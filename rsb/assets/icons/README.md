# Bundled icons

These icons come from Tabler Icons (https://github.com/tabler/tabler-icons), release v3.51.0, MIT licence (see LICENSE). Outline files are normalised to a 24 x 24 view box with `currentColor` stroke 2, round caps and joins. `record`, `play`, `pause` and `battery-4` are filled shapes (`fill="currentColor"`, no stroke); `play`, `pause` and `battery-4` use Tabler's filled variants. `logo.svg` is RSB's own mark, not from Tabler. `memory` is drawn by hand (an upright chip with pins above and below and three bars: no Tabler icon is closer), and `pause` is two plain bars, 4.5 units wide.
